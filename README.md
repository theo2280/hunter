# 🔍 Hunter — Récupération BIP39

Application PWA de récupération guidée de wallet Bitcoin (BIP39 / BIP32 / BIP44).

## ✨ Fonctionnalités

- 🎯 **Mode guidé** : mnémonique partielle avec `?` pour les mots inconnus, préfixes acceptés
- 🎲 **Mode aléatoire** : audit d'entropie
- 🌐 **9 wordlists BIP39** : EN, FR, ES, RU, ZH, DE, IT, HI, PT
- 🔐 **Export chiffré** : Argon2id + AES-256-GCM
- 📊 **Persistance IndexedDB** : reprise automatique après fermeture
- 🧪 **Simulation** : validation sur vecteurs de test BIP officiels
- ⛓️ **Mainnet + Testnet**
- 📴 **100 % offline** : installable comme PWA, fonctionne sans réseau

## 📱 Installation Android

1. Ouvre l'app dans Chrome Android : https://theo2280.github.io/hunter/
2. Menu `⋮` → **Installer l'application**
3. L'icône apparaît sur le launcher
4. Fonctionne hors ligne après le premier lancement

## ⚠️ Usage légal

Usage **strictement** réservé aux wallets que vous possédez ou êtes autorisé à auditer.
Toute utilisation contre des adresses d'autrui est constitutive de vol et d'accès frauduleux.
